Representação eletrônica com Schmitt Trigger

Uma forma clássica de implementar o controle ON/OFF com histerese é usar um comparador com realimentação positiva. O sensor entrega a variável de processo em forma de tensão e o circuito com amp-op cria dois limiares: um para ligar e outro para desligar.

Como funciona o modelo

Circuito Schmitt Trigger

O comparador com histerese (Schmitt Trigger) utiliza um amplificador operacional com realimentação positiva via resistor Rf. Isso cria dois limiares distintos de comutação:

LTP = Vref x Rf / (R1 + Rf)
UTP = LTP + Vcc x R1 / (R1 + Rf)
Histerese = UTP - LTP = Vcc x R1 / (R1 + Rf)

Com R1 = 10 kOhm e Rf = 50 kOhm (histerese de 20%): a banda morta é proporcional à tensão de alimentação e independente do SP. Você pode ajustar o set point sem alterar a largura da histerese.

Lógica de chaveamento

Estado atualCondiçãoAção
OFF PV desce e toca o LTP Aciona ON imediatamente
ON PV sobe e toca o UTP Comuta para OFF imediatamente
Qualquer PV dentro da banda morta Mantém estado atual, sem comutação

Modelo térmico (dT/dt)

A temperatura evolui segundo um balanço de energia de primeira ordem, baseado na Lei de Newton do Resfriamento:

dT/dt = Q_entrada - Q_saida

Q_entrada = (Pwr / 60) x DT [quando ON, senão 0]
Q_saida = k x (T - Tamb) x DT

T(t+DT) = T(t) + Q_entrada - Q_saida

A temperatura de equilíbrio em regime ON, onde dT/dt = 0, é:

T_eq = Tamb + Pwr / (60 x k)

Se T_eq for menor que o UTP, o aquecedor nunca consegue desligar. Essa é uma situação de aquecedor subdimensionado para as perdas do processo.
