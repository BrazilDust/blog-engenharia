SCADA Didático - Alocação de Banco de Capacitores Fixo

Diagrama unifilar simplificado para comparar banco no barramento 13,8 kV, 4,6 kV ou 480 V, com cálculo de P, Q, S e fator de potência.

Comandos Operação

Valor usado no ponto selecionado. A lógica considera apenas um banco conectado por vez para comparar a melhor localização.

Coeficiente didático: queda percentual aproximada = coeficiente x Q líquido total / 10000.

Medições Calculadas Fluxo P/Q

Equações usadas

Q carga = P x tan(arccos(fp))
S = raiz(P² + Q²)
fp = P / S
Q líquido = Q carga - Q capacitor
Queda V% aproximada = k x Q líquido total / 10000

Observação: o modelo é didático. Um estudo real deve usar impedâncias de cabos, transformadores, curto-circuito, regulação, partidas de motores, harmônicos e coordenação de proteção.
